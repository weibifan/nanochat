# 英文数据集国内访问情况（在国内/云端跑 nanochat 的数据源落点）

> **目的**：nanochat 官方使用**英文数据**——分词器在 ClimbMix-400B 上训练 BPE，预训练吃英文文本，SFT/RL 是英文对话（smol-smoltalk / MMLU / GSM8K）。官方所有数据源都挂在 **HuggingFace**（`huggingface.co`）上，而国内网络无法直连 HF。本任务的目标：为 nanochat 的每一类英文数据集，**在国内可直接访问的平台上找到格式 1:1 的镜像**，并给出**已核实的具体仓库、文件布局与下载 URL**，让「数据下载」这一步在国内服务器/本机都能跑通。
>
> 结论先行：**四类英文数据集全部有 ModelScope 官方/组织镜像，且文件格式与 HF 原版完全一致，可整目录直连下载**——`ClimbMix-400B`（预训练+分词器）、`smol-smoltalk`（SFT 对话）、`MMLU`（多选）、`GSM8K`（数学）分别见第 2、3 节。

---

## 1. 为什么要处理"英文数据集的国内访问"

### 1.1 英文数据集的原始托管地（HF）国内不可直连

nanochat 官方数据全部托管在 HuggingFace：

| 数据集 | HF 仓库 | 用途 | 规模 |
|------|--------|------|------|
| **ClimbMix-400B** | `karpathy/climbmix-400b-shuffle` | 分词器 + 预训练（一料两用） | 400B token，6543 个 `shard_*.parquet` |
| **smol-smoltalk** | `HuggingFaceTB/smol-smoltalk` | SFT 通用对话 | train 460K / test 24K |
| **MMLU** | `cais/mmlu` | SFT 多选 + 评测 | 57 学科，训练 100K+ / 测试 14K |
| **GSM8K** | `openai/gsm8k` | SFT 数学 + 评测 | train 7.4K / test 1.3K |

### 1.2 国内网络的现实与"硬绕行"方案

`huggingface.co` 直连在国内 **TCP 超时**（网络层阻断），以前常用的 `hf-mirror.com` 有坑：大文件下载不稳定、**不支持 Datasets Server API（403）**。所以本套件的下载链路**一律改走 ModelScope**（国内可直连、有官方数据镜像仓库），避免再碰 HF 及其镜像。

> **选型原则**：ModelScope 上有格式兼容的镜像就走 ModelScope（快、稳、官网维护）；只有 ModelScope 没有时才考虑 Gitee 的 HF 镜像组织 `hf-datasets/*`（本套件实测 ModelScope 全都有，因此不需要 Gitee）。

## 2. nanochat 各英文数据集的 ModelScope 候选

> 第 1 列的英文数据集即本套件最终要用的数据——这里**不替换语言、只换下载源**。以下候选均为**已核实**仓库（本节后续的 URL/文件结构都通过 ModelScope API 实测确认）。

### 2.1 ClimbMix-400B（分词器 + 预训练）→ ModelScope 同仓库镜像

> 该语料**一料两用**：既用前 ~2B 字符训练分词器，也用更大规模做预训练（官方 `dataset.py -n N` 按 shard 数选）。数据源只需换一处：`nanochat/dataset.py` 的 `BASE_URL`。

| 候选（Scope） | 仓库布局 / 说明 | 与 HF 原版的对应关系 |
|---------|------------|---------------|
| **`AI-ModelScope/climbmix-400b-shuffle`** | 共 **6543 个 `shard_*.parquet`**（`shard_00000` ~ `shard_06542`，与 HF 原版分片命名一致） | **文件即原版**，`dataset.py` 只改 BASE_URL 即可复用全部下载逻辑 |

- 注意与 `AI-ModelScope/ClimbMix`（另一个仓库）区分：后者是 **tokenizer 过的 `.tokenized.jsonl`** 格式，不是 parquet，**不能**直接喂给 `dataset.py`。

### 2.2 smol-smoltalk（SFT 通用对话）→ ModelScope / `HuggingFaceTB/smol-smoltalk`

| 候选（Scope） | 仓库布局 / 文件 | 与 HF 原版的对应 |
|------|------------|----------------|
| **`HuggingFaceTB/smol-smoltalk`** | 目录 `data/` 下 `train-0000X-of-00004.parquet`（0~3，共 4 片）+ `test-00000-of-00001.parquet` | 文件名与 HF 版一致（HF `/data/...`） |

- 单文件 URL 可直连：`https://www.modelscope.cn/datasets/HuggingFaceTB/smol-smoltalk/resolve/master/data/train-00000-of-00004.parquet`

### 2.3 MMLU（多选 / 评测） → ModelScope / `cais/mmlu`

| 候选（Scope） | 仓库布局 / 文件 | 与 HF 原版的对应 |
|------|------------|----------------|
| **`cais/mmlu`** ✅（推荐） | 根目录下按**主题（57 学科）**与 `all / auxiliary_train` 等分目录的 parquet | 与 HF 的 `cais/mmlu` **分片结构一致**，`all/auxiliary_train-*.parquet` / `all/test-*.parquet`（SFT 混料正好用 `all`） |

- 另一候选 `modelscope/mmlu` 是**旧格式**（单个 `data.tar` + loader），不适合 `load_hub_dataset` 直接读 parquet，**不推荐**。
- 可用 URL 示例：`https://www.modelscope.cn/datasets/cais/mmlu/resolve/master/all/auxiliary_train-00000-of-00001.parquet`

### 2.4 GSM8K（数学）→ `AI-ModelScope/gsm8k`

| 候选（Scope） | 仓库布局 / 文件 | 与 HF 原版的对应 |
|------|------------|----------------|
| **`AI-ModelScope/gsm8k`** | 目录 `main/` 下 `train-00000-of-00001.parquet`、`test-00000-of-00001.parquet` | 与 HF `openai/gsm8k main` split 一致 |

## 3. 选型与下载落地

### 3.1 推荐组合（一句话结论）

> 数据源与官方**保持一致**（全部英文数据中心库），只是把 HF 换成 ModelScope 镜像。分词器 / 预训练 / SFT 无任何数据集替换，只改「下载源」。

| 阶段 | 官方（HF） | 本套件（ModelScope） |
|------|-----------|-------------------|
| Tokenizer | `karpathy/climbmix-400b-shuffle` 前 ~2B 字符 | `AI-ModelScope/climbmix-400b-shuffle` 前 ~2B 字符 |
| 预训练 | ClimbMix-400B | 同上仓库（同一批下载的 shard） |
| SFT 对话 | `HuggingFaceTB/smol-smoltalk` | `HuggingFaceTB/smol-smoltalk`（Scope 镜像） |
| SFT / 评测多选 | `cais/mmlu` | `cais/mmlu`（Scope 镜像） |
| SFT / RL 数学 | `openai/gsm8k` | `AI-ModelScope/gsm8k` |

> 与 runs-in-ch（中文数据集选型）的根本区别：runs-in-zh-en **不替换数据、不改语言**，只保证「英文原始数据在纯内网/云端也能下载」——因此分词器、预训练、SFT 全链路保持英文原版，`dataset.py`/`tasks/*.py` 只改下载源即可。

### 3.2 已核实的关键事实（均可直接复用）

1. **ModelScope resolve 下载链路**（已用 curl 实测）：请求 `https://www.modelscope.cn/datasets/<owner>/<repo>/resolve/master/<file>` 会 **302 跳转到 CDN**（`cdn-lfs-cn-1.modelscope.cn`）并返回 **200**，可直接 `wget`/`curl`/`urllib` 直连；无需登录、无需 token。示例：
   ```bash
   curl -LO https://www.modelscope.cn/datasets/AI-ModelScope/gsm8k/resolve/master/main/train-00000-of-00001.parquet        # 2.3MB，秒下
   curl -LO https://www.modelscope.cn/datasets/AI-ModelScope/climbmix-400b-shuffle/resolve/master/shard_00000.parquet   # ~92MB/片
   ```
2. **ClimbMix 分片命名与最大片号**：`shard_%05d.parquet`、最大到 `shard_06542`，与 `dataset.py` 的 `index_to_filename` / `MAX_SHARD=6542` 完全兼容，`python -m nanochat.dataset -n N` 语义原样保留。
3. **smol-smoltalk**：4 片 train + 1 片 test，字节数与 HF 原版一致（每片 ~230MB，train 合计 ~920MB）。
4. **MMLU**：`all/` 目录有 `auxiliary_train / test / dev / validation` 4 个文件，SFT 混料只取 `auxiliary_train` + `test`。

### 3.3 与「modelscope/mmlu」（旧格式）的坑

`modelscope/mmlu`（注意不是 `cais/mmlu`）仓库根目录只有一个 `data.tar`（~160MB tar）和加载器脚本，**不是 parquet 分片**，`load_hub_dataset` 无法直接读。**勿用**；用 `cais/mmlu`。

## 4. 代码侧修改思路（零覆盖、后缀文件）

全部通过**新增 `_zh.py` 后缀文件**实现（放在原文件同目录、通过 `sys.modules` 或导入路径重定向），**不改任何原始文件**：

| 文件 | 现状（HF） | 改为（ModelScope） |
|------|-----------|------------------|
| `nanochat/dataset.py` | `BASE_URL` 指向 HF `karpathy/climbmix-400b-shuffle` | 新增 `dataset_zh.py`：`BASE_URL` → `AI-ModelScope/climbmix-400b-shuffle` |
| `tasks/common.py` | `load_hub_dataset()` 用 HF API | 新增 `common_zh.py`：读到本地 `task_data/` 缓存，不联网（数据已由 `download_sft_data_zh.py` 预下载） |
| `tasks/download_sft_data_zh.py`（新增） | — | 用 `resolve` URL 下载 SmolTalk / MMLU / GSM8K 到 `data/task_data/` |

> 说明：预训练/tokenizer 用 `dataset_zh.py`（只改 URL 即可）；SFT 任务先 `download_sft_data_zh.py` 把三份数据落到本地缓存，再用 `common_zh.py` 读本地，全链路不再产生任何 HF/请求。

## 附：下载方式速查（ModelScope）

```bash
# 1) 单文件直连（最通用，支持 wget/curl/python-requests）
wget -O shard_00000.parquet https://www.modelscope.cn/datasets/AI-ModelScope/climbmix-400b-shuffle/resolve/master/shard_00000.parquet

# 2) 用官方 SDK（modelscope）
pip install modelscope
modelscope download --dataset AI-ModelScope/gsm8k --local_dir ./gsm8k
modelscope download --dataset cais/mmlu --local_dir ./mmlu

# 3) 循环下载 ClimbMix 前 8 片（分词器 + 玩具预训练够用）
for i in $(seq -w 0 7); do
  curl -LO "https://www.modelscope.cn/datasets/AI-ModelScope/climbmix-400b-shuffle/resolve/master/shard_000${i}.parquet"
done
```

> 在 `runs-in-zh-en` 套件中，这些由 `step1_prepare_data.py` / `dataset_zh.py` 自动完成，手动下载主要用于排障与核对。
