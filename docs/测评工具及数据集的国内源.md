# 测评工具及数据集的国内源

> 对应《nanochat中大模型的评估方法》3.7.1 节。国内不加代理无法访问 huggingface.co、github.com、karpathy-public S3 等源，本文为其中涉及的**自动下载的外部数据源**逐一提供国内替代方案（ModelScope、Gitee、hf-mirror.com 等免代理网站）。

## 1. 总览

| 数据源（3.7.1） | 原获取地址 | 用途 | 国内替代 | 接入方式 |
|---|---|---|---|---|
| eval_bundle.zip（约 26MB） | `karpathy-public.s3.us-west-2.amazonaws.com/eval_bundle.zip` | 基础模型 CORE 评测（22 个任务 jsonl + core.yaml + eval_meta_data.csv） | 无现成国内 zip 镜像；见 §2 的 3 个替代路径 | 目录预放置（代码检测到目录存在则跳过下载） |

## 2. eval_bundle.zip（CORE 评测包）国内获取路径

现状说明：截至本文档撰写时，**在 ModelScope / Gitee 上未找到 eval_bundle.zip 的现成国内镜像**（Gitee 代码搜索 `eval_bundle`、`nanochat` 均为空）。可用以下 3 条路径之一解决：

### 路径 A（推荐，零改造）：目录预放置

nanochat 在 `scripts/base_eval.py:65` 先判断 `<base_dir>/eval_bundle` 目录是否存在，**存在则跳过下载**。因此只需把评测包一次性放到该目录即可：

```bash
# 1) 用任意可访问的方式拿到 eval_bundle.zip 并解压出 eval_bundle 目录
#    （例如让有条件的同学下载后传给你；或见路径 C 自行从国内源组装）
unzip -q eval_bundle.zip
# 2) 放到 base 目录（默认 ~/.cache/nanochat）
mkdir -p ~/.cache/nanochat
mv eval_bundle ~/.cache/nanochat/
# 3) 之后 base_eval.py / chat_eval.py 检测到目录存在，不再联网下载
```

> 若需改变默认位置，可用环境变量 `NANOCHAT_BASE_DIR` 指定 base 目录（见 `nanochat/common.py:80-91`）。

### 路径 B（国内云平台免代理）：模力方舟预置

Gitee 官方 AI 平台**模力方舟**（ai.gitee.com）的 nanochat 实战教程已预置该评测包，国内直接访问、无需代理：

```bash
# 教程文档：https://ai.gitee.com/docs/compute/practices/nanochat
ln -s /mnt/moark-models/eval_bundle "$NANOCHAT_BASE_DIR/eval_bundle"
```

适合不想在自己机器上折腾下载、直接在国产云平台（昇腾/Ascend 环境）上跑 nanochat 的场景。

### 路径 C：从 Gitee/ModelScope 逐任务组装（工作量大，仅兜底）

eval_bundle 的 22 个任务数据在 Gitee `hf-datasets` 组织、ModelScope 均有对应镜像（见 §3 表），可逐任务下载后按 eval_bundle 的 jsonl 格式（multiple_choice 类：`query`/`choices`/`gold`；language_modeling 类：`context`/`continuation`）重新组装，再配合 `core.yaml` 与 `eval_meta_data.csv`。因格式转换与 few-shot 构造较繁琐，**仅作为无法走路径 A/B 时的兜底**。

## 3. HuggingFace 标准数据集（ChatCORE / SmolTalk）国内替代

### 3.1 各数据集镜像清单（均已核实页面存在）

| 原 HF 数据集 | 任务 | ModelScope 数据集 ID | Gitee 镜像仓库（hf-datasets 组织） |
|---|---|---|---|
| `cais/mmlu` | MMLU | `cais/mmlu`、`opencompass/mmlu` | `hf-datasets/mmlu` |
| `allenai/ai2_arc` | ARC-Easy / ARC-Challenge | `opencompass/ai2_arc`（注意：`modelscope/ai2_arc` 只有解析脚本、无 parquet 数据） | `hf-datasets/ai2_arc` |
| `openai/gsm8k` | GSM8K | `AI-ModelScope/gsm8k`、`opencompass/gsm8k`（`modelscope/gsm8k` 同样只有脚本） | `hf-datasets/gsm8k` |
| `openai/openai_humaneval` | HumanEval | `opencompass/humaneval`（`modelscope/humaneval` 只有脚本） | `hf-datasets/openai_humaneval` |
| `HuggingFaceTB/smol-smoltalk` | SmolTalk（训练用） | `HuggingFaceTB/smol-smoltalk` | `hf-datasets/smol-smoltalk` |

> Gitee `hf-datasets` 组织（gitee.com/hf-datasets）是 HF 热门数据集的自动镜像，命名规则为 `hf-datasets/<HF 仓库名>`，含 `main`/`script` 分支，可直接 `git clone`。
>
> ⚠️ **ModelScope 数据集核实（2026-08-09 实际下载验证）**：ModelScope 上有两类同名数据集——一类是**数据镜像**（含 parquet，如 `opencompass/*`、`AI-ModelScope/gsm8k`、`cais/mmlu`），另一类只是 **HF datasets 解析脚本仓库**（仅 `*.py`，无数据，如 `modelscope/ai2_arc`、`modelscope/humaneval`、`modelscope/gsm8k`）。下载前务必用 tree API 核实含 `.parquet` 文件。可直接用单文件直链下载 test 分片（见下）。

### 3.2 接入方式一（零代码改动，最推荐）：`HF_ENDPOINT` 指向 hf-mirror.com

nanochat 的数据下载函数 `tasks/common.py:45 load_hub_dataset` 使用 `huggingface_hub` 的 `HfApi` / `hf_hub_url`，**原生支持 `HF_ENDPOINT` 环境变量**指向镜像站（代码注释已明确说明）。只需设置：

```bash
export HF_ENDPOINT=https://hf-mirror.com    # Linux/macOS
# Windows (PowerShell)： $env:HF_ENDPOINT="https://hf-mirror.com"
```

之后运行 `chat_eval.py` 等脚本即可从 hf-mirror.com（国内免代理）拉取 parquet，其余逻辑完全不变。

### 3.3 接入方式二：从 ModelScope / Gitee 下载后「预放置」parquet

若不想依赖 hf-mirror.com，可从 ModelScope 或 Gitee 把对应数据集下载到本机，再放入 nanochat 期望的目录结构，使 `load_hub_dataset` 跳过联网下载。

nanochat 期望的目录布局（`tasks/common.py:54-69`）：

```
<base_dir>/task_data/<repo_id 的 / 换成 -->/<subset>/<split>/
├── manifest.json          # ["00000.parquet", ...]
├── 00000.parquet
└── ...
```

各数据集对应的 subset/split：

| 数据集 | subset | split | 数据文件名前缀 |
|---|---|---|---|
| `cais/mmlu` | `all` | `test` | `all/test-*.parquet` |
| `allenai/ai2_arc` | `ARC-Easy` / `ARC-Challenge` | `test` | `ARC-Easy/test-*.parquet` 等 |
| `openai/gsm8k` | `main` | `test` | `main/test-*.parquet` |
| `openai/openai_humaneval` | `openai_humaneval` | `test` | `openai_humaneval/test-*.parquet` |
| `HuggingFaceTB/smol-smoltalk` | `default` | `train` | `data/train-*.parquet` |

**（实测可用，2026-08-09）ModelScope 单文件直链下载**：只需下载需要的分片，不必全量下载，1~2 秒/文件：

```bash
# 格式：https://modelscope.cn/api/v1/datasets/<namespace>/<name>/repo?Revision=master&FilePath=<路径>
# MMLU (cais/mmlu)
curl -sL -o mmlu_test.parquet "https://modelscope.cn/api/v1/datasets/cais/mmlu/repo?Revision=master&FilePath=all/test-00000-of-00001.parquet"
# ARC-Easy / ARC-Challenge (opencompass/ai2_arc)
curl -sL -o arc_easy_test.parquet "https://modelscope.cn/api/v1/datasets/opencompass/ai2_arc/repo?Revision=master&FilePath=ARC-Easy/test-00000-of-00001.parquet"
curl -sL -o arc_challenge_test.parquet "https://modelscope.cn/api/v1/datasets/opencompass/ai2_arc/repo?Revision=master&FilePath=ARC-Challenge/test-00000-of-00001.parquet"
# GSM8K (AI-ModelScope/gsm8k)
curl -sL -o gsm8k_test.parquet "https://modelscope.cn/api/v1/datasets/AI-ModelScope/gsm8k/repo?Revision=master&FilePath=main/test-00000-of-00001.parquet"
# HumanEval (opencompass/humaneval)
curl -sL -o humaneval_test.parquet "https://modelscope.cn/api/v1/datasets/opencompass/humaneval/repo?Revision=master&FilePath=openai_humaneval/test-00000-of-00001.parquet"
```

下载后把 parquet 放入 nanochat 期望目录（`task_data/<slug>/<subset>/<split>/`）并写 `manifest.json` 即可。

以 ModelScope 为例（`cais/mmlu` 的 test 分片，全量下载方式）：

```bash
pip install modelscope
# 下载整个数据集（ModelScope 仓库内文件布局与 HF 一致，含各分片 parquet）
modelscope download --dataset cais/mmlu --local_dir ./mmlu

# 组装成 nanochat 期望的目录（以默认 base_dir ~/.cache/nanochat 为例）
SLUG="cais--mmlu"                        # repo_id 的 "/" 换成 "--"
DEST="$HOME/.cache/nanochat/task_data/$SLUG/all/test"
mkdir -p "$DEST"
# 把 mmlu 里 all/test-*.parquet 重命名拷入，编号从 00000 起
i=0
for f in ./mmlu/all/test-*.parquet; do
  cp "$f" "$DEST/$(printf '%05d.parquet' $i)"; i=$((i+1))
done
# 写 manifest.json
printf '["00000.parquet","00001.parquet",...]' > "$DEST/manifest.json"
```

之后运行 `chat_eval.py` 即直接读取本地数据。Gitee 版本把 `modelscope download` 换成 `git clone https://gitee.com/hf-datasets/mmlu.git` 后同样处理即可。

> 提示：ModelScope 已提供与 HF 相同的分片 parquet，可先用 `modelscope` SDK 或 tree API（`/api/v1/datasets/<id>/repo/tree?Revision=master&Recursive=true`）查看仓库文件列表确认确切文件名再组装 manifest。

## 4. 结论

1. **ChatCORE 评测用 5 个 HF 数据集**：国内替代完备——推荐 `HF_ENDPOINT=https://hf-mirror.com`（零改动），或从 ModelScope（`cais/mmlu`、`opencompass/ai2_arc`、`AI-ModelScope/gsm8k`、`opencompass/humaneval`）单文件直链下载预放置。
2. **eval_bundle.zip（CORE）**：暂无现成国内 zip 镜像；推荐「预放置」到 `~/.cache/nanochat/eval_bundle`，或使用模力方舟预置环境；逐任务组装仅作兜底。
3. 实测下载结果（2026-08-09，ModelScope 国内 CDN）：MMLU test 3.34MB、ARC-Easy 0.33MB、ARC-Challenge 0.19MB、GSM8K 0.40MB、HumanEval 0.08MB，各文件 1~2 秒下载完成；eval_bundle.zip 24.85MB（预放置）。
4. ⚠️ ModelScope 同名数据集需区分**数据镜像**（有 parquet）与**解析脚本仓库**（仅 *.py）；文档中列出的均为已验证可下载的数据镜像。
